# Proyecto-2-EDD
SuperMetroMendeley: Hash Table y Árboles AVL. 

Este proyecto se basa en la implementacion de una tabla de dispersión que almacena la información de una clase, que contiene árticulos y resumenes científicos. La información de esta tabla es visitada y recorrida de distintas formas madiante árboles AVL que permitirán la búsqueda y visualización de manera eficiente.
